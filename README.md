# Model Compass (site)

Public, static site for Model Compass: which Picsart AI model should you use for your task?
Generated by the `model-compass` pipeline (`uv run model-compass export`). Do not edit generated
files by hand; change the templates in the pipeline and re-export.

Built by Vilya Poghosyan with Picsart models. Images carry the Picsart AI label.
