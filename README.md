# Model Compass (site)

Public, static site for Model Compass: which Picsart AI model should you use for your task?
Generated by the `model-compass` pipeline (`uv run model-compass export`). Do not edit generated
files by hand; change the templates in the pipeline and re-export.

Personal project by Vilya Poghosyan, who works at Picsart; not an official Picsart page.
Benchmark data CC BY 4.0; site code MIT (see `LICENSE`). Every image and clip was made with
Picsart (AI Playground) and carries the Picsart AI label; the generated media are not part of
the CC BY 4.0 release and are shown under Picsart's terms.

## Deploying on GitHub Pages

GitHub Pages serves a project site at `https://<user>.github.io/<repo>/`, and every absolute
URL in this build (canonical links, sitemap, Open Graph, JSON-LD, asset base path) is generated
from `site_url` in the pipeline's `data/site.yaml`. The two must agree:

- `site_url` is currently `https://vilyapoghosyan.github.io/model-compass`, so this repository
  must be created on GitHub as **`model-compass`** (the local folder name does not matter), or
- change `site_url` to `.../model-compass-site`, re-export and copy again.

`uv run model-compass export` prints a warning when the `origin` remote's repo name and the
`site_url` path differ. Pages settings: deploy from the `main` branch, root folder; `.nojekyll`
is already in the build. Builds made from sample data carry `noindex` and `Disallow: /` and
must not be pushed.
