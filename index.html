    How we measure

    1. Same requests to every model. 80 prompts written like real users write them, 8 tasks, 12 models you can pick in Picsart's AI Playground, every output kept with its settings and cost.
    2. Scores you can check. CLIP similarity for prompt match, an aesthetic predictor for looks, and OCR for tasks where the text must be spelled right.
    3. A judge that cannot cheat. An AI judge ranks each prompt's outputs twice in shuffled order without seeing model names; humans spot-check it. Rankings become Plackett–Luce ratings with bootstrap error bars.
